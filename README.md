## Как пользоваться репозиторием

1. Выберите актуальную дисциплину в первой таблице.
2. Откройте её README и перейдите по ссылке на нужную лекцию.
3. Если к занятию приложены примеры, изучайте код в соответствующей папке.
4. Собственные решения храните **в личных репозиториях**; порядок сдачи указан преподавателем в Notion и системе учёта работ.

Для локального просмотра исходников:
```bash
git clone --branch dev https://github.com/anilate-sq/dev_2023.git
```

> Репозиторий преподавателя используется для получения учебных материалов. Отправлять сюда свои решения с помощью `git push` не нужно. Содержание лекций и правила сдачи уточняйте в Notion.
