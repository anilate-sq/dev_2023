# Что такое переменная?

**Переменная** — именованная область памяти, в которой во время выполнения скрипта хранится некоторое значение.

Например:

```sql
DECLARE @age INT = 18;
```

Здесь:

```text
@age
```

— имя переменной.

```text
INT
```

— её тип.

```text
18
```

— начальное значение.

В T-SQL локальные переменные начинаются с символа:

```text
@
```

Например:

```text
@age
@name
@studentCount
@average
```

---

# Объявление переменной

Для объявления переменной используется:

```sql
DECLARE
```

Например:

```sql
DECLARE @age INT;
```

Мы создали переменную:

```text
@age
```

типа:

```text
INT
```

Но пока значение не задано.

Можно сразу указать значение:

```sql
DECLARE @age INT = 18;
```

Теперь переменная содержит:

```text
18
```

---

# Основные типы данных

При объявлении переменной необходимо указать её тип.

Наиболее часто используемые типы:

| Тип            | Назначение                      |
| -------------- | ------------------------------- |
| `INT`          | целое число                     |
| `BIGINT`       | большое целое число             |
| `DECIMAL(p,s)` | число с фиксированной точностью |
| `FLOAT`        | число с плавающей точкой        |
| `VARCHAR(n)`   | строка                          |
| `NVARCHAR(n)`  | Unicode-строка                  |
| `DATE`         | дата                            |
| `DATETIME2`    | дата и время                    |
| `BIT`          | логическое значение `0` или `1` |

Например:

```sql
DECLARE @age INT = 18;
DECLARE @name NVARCHAR(100) = N'Иван';
DECLARE @average DECIMAL(5,2) = 4.75;
DECLARE @birthday DATE = '2008-05-12';
DECLARE @isActive BIT = 1;
```

---

# Почему тип данных имеет значение?

Тип определяет, какие значения может хранить переменная.

Например:

```sql
DECLARE @age INT = 18;
```

В неё можно записать целое число:

```sql
SET @age = 20;
```

Но нельзя записать обычный текст:

```sql
SET @age = N'Иван';
```

SQL Server выдаст ошибку преобразования типов.

Поэтому при объявлении переменной необходимо понимать, какие данные она будет хранить.

# Изменение значения переменной

После создания переменной её значение можно изменить.

Для этого можно использовать:

```sql
SET
```

Например:

```sql
DECLARE @age INT = 18;

SET @age = 19;

SELECT @age;
```

Результат:

```text
19
```

То есть:

```text
DECLARE
```

— создаёт переменную.

```text
SET
```

— изменяет её значение.

---

# SET и SELECT

В T-SQL значение переменной можно получить не только с помощью `SET`.

Например:

```sql
DECLARE @age INT;

SELECT @age = 18;

SELECT @age;
```

Но `SELECT` особенно полезен, когда значение необходимо получить из таблицы.

Например:

```sql
DECLARE @studentCount INT;

SELECT @studentCount = COUNT(*)
FROM college.students;

SELECT @studentCount;
```

Здесь происходит следующее:

```text
1. Создаём переменную.
2. Выполняем COUNT().
3. Получаем количество студентов.
4. Сохраняем результат в переменную.
5. Выводим переменную.
```

Это один из распространённых сценариев использования переменных в T-SQL.

---

# Получение одного значения из таблицы

Переменная может получить значение из конкретной строки.

Например:

```sql
DECLARE @studentName NVARCHAR(100);

SELECT @studentName = name
FROM college.students
WHERE id = 1;

SELECT @studentName;
```

Если студент с `id = 1` существует, переменная получит его имя.

Например:

```text
Иван
```

Таким образом, T-SQL позволяет не только создавать значения вручную, но и получать их из базы данных.

# Арифметические выражения

T-SQL позволяет выполнять математические операции.

Основные операторы:

| Оператор | Назначение         |
| -------- | ------------------ |
| `+`      | сложение           |
| `-`      | вычитание          |
| `*`      | умножение          |
| `/`      | деление            |
| `%`      | остаток от деления |

Например:

```sql
DECLARE @a INT = 10;
DECLARE @b INT = 3;

SELECT @a + @b;
SELECT @a - @b;
SELECT @a * @b;
SELECT @a / @b;
SELECT @a % @b;
```

Результат:

```text
13
7
30
3
1
```

Обратите внимание:

```text
10 / 3 = 3
```

потому что обе переменные имеют тип `INT`.

---

# Целочисленное и обычное деление

Тип данных влияет на результат арифметической операции.

Например:

```sql
SELECT 10 / 3;
```

Результат:

```text
3
```

Потому что используется целочисленное деление.

Если нам нужен результат с дробной частью, необходимо использовать подходящий тип:

```sql
SELECT 10.0 / 3;
```

Результат будет примерно:

```text
3.333333
```

Поэтому при работе с вычислениями важно учитывать типы данных.

---

# Приоритет операторов

В выражениях действует определённый порядок выполнения операций.

Например:

```sql
SELECT 10 + 5 * 2;
```

Сначала выполняется умножение:

```text
5 * 2 = 10
```

Затем:

```text
10 + 10 = 20
```

Результат:

```text
20
```

Если необходимо изменить порядок выполнения, используются скобки:

```sql
SELECT (10 + 5) * 2;
```

Теперь сначала:

```text
10 + 5 = 15
```

затем:

```text
15 * 2 = 30
```

Результат:

```text
30
```

Поэтому скобки позволяют явно указать порядок вычислений.

# Операторы сравнения

Для сравнения значений используются:

| Оператор | Значение         |
| -------- | ---------------- |
| `=`      | равно            |
| `<>`     | не равно         |
| `>`      | больше           |
| `<`      | меньше           |
| `>=`     | больше или равно |
| `<=`     | меньше или равно |

Например:

```sql
DECLARE @age INT = 18;

SELECT @age >= 18;
```

Результатом логического выражения будет:

```text
1
```

В SQL Server значение:

```text
1
```

обычно означает истину.

А:

```text
0
```

— ложь.

---

# Логические операторы

Условия можно объединять.

Основные операторы:

```text
AND
OR
NOT
```

Например:

```sql
DECLARE @age INT = 18;

IF @age >= 18 AND @age < 30
    PRINT N'Возраст от 18 до 29 лет';
```

Здесь одновременно проверяются два условия:

```text
@age >= 18
```

и:

```text
@age < 30
```

Оба должны быть истинными.

---

# Оператор AND

`AND` означает:

> оба условия должны выполняться.

Например:

```sql
SELECT *
FROM college.students
WHERE age >= 18
  AND age <= 20;
```

Мы получим студентов, возраст которых находится в диапазоне от 18 до 20 лет.

---

# Оператор OR

`OR` означает:

> достаточно выполнения хотя бы одного условия.

Например:

```sql
SELECT *
FROM college.students
WHERE age = 17
   OR age = 18;
```

Будут найдены студенты возрастом 17 или 18 лет.

---

# Оператор NOT

`NOT` меняет результат условия на противоположный.

Например:

```sql
SELECT *
FROM college.students
WHERE NOT age = 18;
```

Такой запрос выберет студентов, которым не 18 лет.

Чаще вместо такого варианта используют:

```sql
WHERE age <> 18;
```

Но `NOT` особенно полезен при работе со сложными условиями.

---

# IF ... ELSE

Мы уже встречались с конструкцией:

```sql
IF ... ELSE
```

Она позволяет выполнить разные команды в зависимости от условия.

Например:

```sql
DECLARE @age INT = 18;

IF @age >= 18
    PRINT N'Совершеннолетний';
ELSE
    PRINT N'Несовершеннолетний';
```

Если условие:

```text
@age >= 18
```

истинно, выполняется первая команда.

Если ложно — вторая.

---

# IF с несколькими командами

Если при выполнении условия необходимо выполнить несколько инструкций, используется:

```sql
BEGIN
END
```

Например:

```sql
DECLARE @age INT = 18;

IF @age >= 18
BEGIN
    PRINT N'Совершеннолетний';
    PRINT N'Доступ разрешён';
END
ELSE
BEGIN
    PRINT N'Несовершеннолетний';
    PRINT N'Доступ запрещён';
END
```

`BEGIN ... END` объединяет несколько инструкций в один блок.

---

# Несколько условий

Можно использовать несколько ветвей:

```sql
DECLARE @age INT = 18;

IF @age < 18
    PRINT N'Несовершеннолетний';
ELSE IF @age < 25
    PRINT N'Молодой человек';
ELSE
    PRINT N'Возраст 25 лет и старше';
```

Проверки выполняются сверху вниз.

В нашем случае:

```text
18 < 18 → нет

18 < 25 → да
```

Поэтому будет выполнено:

```text
Молодой человек
```

---

# Что такое CASE?

`CASE` — выражение, которое позволяет выбрать одно значение в зависимости от условия.

Проще говоря:

```text
если условие → одно значение
иначе → другое значение
```

Например:

```sql
SELECT
    name,
    age,
    CASE
        WHEN age >= 18 THEN N'Совершеннолетний'
        ELSE N'Несовершеннолетний'
    END AS status
FROM college.students;
```

Получим примерно:

| name    | age | status             |
| ------- | --: | ------------------ |
| Иван    |  18 | Совершеннолетний   |
| Мария   |  17 | Несовершеннолетний |
| Алексей |  18 | Совершеннолетний   |

---

# CASE и IF — в чём разница?

Это важный момент.

`IF` управляет выполнением инструкций.

Например:

```sql
IF @age >= 18
    PRINT N'Совершеннолетний';
```

А `CASE` возвращает значение.

Например:

```sql
SELECT
    CASE
        WHEN age >= 18 THEN N'Совершеннолетний'
        ELSE N'Несовершеннолетний'
    END
FROM college.students;
```

Можно запомнить так:

```text
IF
↓
решает, какой код выполнить

CASE
↓
решает, какое значение вернуть
```

---

# CASE внутри SELECT

Одно из главных преимуществ `CASE` — возможность использовать его непосредственно в запросах.

Например:

```sql
SELECT
    name,
    age,
    CASE
        WHEN age < 18 THEN N'Несовершеннолетний'
        WHEN age < 20 THEN N'18–19 лет'
        ELSE N'20 лет и старше'
    END AS age_group
FROM college.students;
```

Получаем дополнительный столбец:

```text
name       age    age_group
--------------------------------
Иван       18     18–19 лет
Мария      17     Несовершеннолетний
Алексей    20     20 лет и старше
```

При этом данные в таблице не изменяются.

`CASE` только формирует результат запроса.

---

# CASE с несколькими условиями

Можно создать более сложную классификацию.

Например, определим результат студента:

```sql
SELECT
    name,
    average_grade,
    CASE
        WHEN average_grade >= 4.5 THEN N'Отлично'
        WHEN average_grade >= 3.5 THEN N'Хорошо'
        WHEN average_grade >= 3.0 THEN N'Удовлетворительно'
        ELSE N'Неудовлетворительно'
    END AS result
FROM college.students;
```

Проверки выполняются сверху вниз.

Например, если:

```text
average_grade = 4.7
```

сработает:

```sql
WHEN average_grade >= 4.5
```

и будет возвращено:

```text
Отлично
```

Остальные условия уже проверяться не будут.

---

# Важен порядок условий

Рассмотрим:

```sql
CASE
    WHEN age >= 18 THEN N'18+'
    WHEN age >= 20 THEN N'20+'
    ELSE N'Младше 18'
END
```

На первый взгляд кажется, что студенту 20 лет будет присвоено:

```text
20+
```

Но это не так.

Для `age = 20` первое условие:

```text
age >= 18
```

уже является истинным.

Поэтому результат:

```text
18+
```

Следовательно, условия в `CASE` необходимо располагать в правильном порядке.

Например:

```sql
CASE
    WHEN age >= 20 THEN N'20+'
    WHEN age >= 18 THEN N'18–19'
    ELSE N'Младше 18'
END
```

Теперь результат будет правильным.

---

# Простой CASE

Существует другой вариант конструкции `CASE`.

Например:

```sql
CASE status
    WHEN 1 THEN N'Активен'
    WHEN 0 THEN N'Неактивен'
    ELSE N'Неизвестно'
END
```

Здесь `CASE` сравнивает одно значение с несколькими вариантами.

Например:

```sql
SELECT
    name,
    is_active,
    CASE is_active
        WHEN 1 THEN N'Активен'
        WHEN 0 THEN N'Неактивен'
        ELSE N'Неизвестно'
    END AS status
FROM college.students;
```

---

# Простой и поисковый CASE

Можно выделить два основных варианта.

**Простой `CASE`:**

```sql
CASE value
    WHEN 1 THEN ...
    WHEN 2 THEN ...
    ELSE ...
END
```

Используется, когда необходимо сравнить одно значение с конкретными вариантами.

**Поисковый `CASE`:**

```sql
CASE
    WHEN condition THEN ...
    WHEN condition THEN ...
    ELSE ...
END
```

Используется, когда нужны полноценные условия.

Например:

```sql
CASE
    WHEN age >= 18 THEN N'Совершеннолетний'
    ELSE N'Несовершеннолетний'
END
```

В практической работе поисковый `CASE` встречается очень часто.

---

# CASE с вычислениями

`CASE` может возвращать не только текст.

Например:

```sql
SELECT
    name,
    age,
    CASE
        WHEN age >= 18 THEN 1
        ELSE 0
    END AS can_vote
FROM college.students;
```

Получим:

| name    | age | can_vote |
| ------- | --: | -------: |
| Иван    |  18 |        1 |
| Мария   |  17 |        0 |
| Алексей |  20 |        1 |

Таким образом, `CASE` может возвращать числа, строки и другие значения.

---

# CASE и ORDER BY

`CASE` можно использовать не только в списке `SELECT`.

Например, можно изменить порядок сортировки.

Предположим, мы хотим сначала показать несовершеннолетних:

```sql
SELECT
    name,
    age
FROM college.students
ORDER BY
    CASE
        WHEN age < 18 THEN 0
        ELSE 1
    END,
    age;
```

SQL Server сначала отсортирует данные по результату `CASE`.

Получается:

```text
0 → несовершеннолетние
1 → совершеннолетние
```

А затем внутри групп используется возраст.

---

# CASE и UPDATE

`CASE` можно использовать и при изменении данных.

Например:

```sql
UPDATE college.students
SET status =
    CASE
        WHEN age >= 18 THEN N'Совершеннолетний'
        ELSE N'Несовершеннолетний'
    END;
```

Для каждой строки SQL Server вычислит результат отдельно.

В результате статус будет установлен в зависимости от возраста.

Важно понимать:

```text
SELECT + CASE
```

только формирует результат запроса.

А:

```text
UPDATE + CASE
```

уже изменяет данные в таблице.

# Работа с NULL

При работе с базами данных необходимо помнить о значении:

```text
NULL
```

`NULL` означает отсутствие значения.

Например:

```text
phone
----------------
+79990000000
NULL
+79991111111
```

`NULL` — это не:

```text
0
```

и не:

```text
''
```

Это отсутствие значения.

---

# Сравнение с NULL

Нельзя корректно проверять `NULL` обычным оператором:

```sql
WHERE phone = NULL
```

Вместо этого используется:

```sql
IS NULL
```

Например:

```sql
SELECT *
FROM college.students
WHERE phone IS NULL;
```

Чтобы найти строки, где значение существует:

```sql
SELECT *
FROM college.students
WHERE phone IS NOT NULL;
```

---

# NULL внутри CASE

`CASE` можно использовать для обработки отсутствующих значений.

Например:

```sql
SELECT
    name,
    CASE
        WHEN phone IS NULL THEN N'Телефон не указан'
        ELSE phone
    END AS phone
FROM college.students;
```

Теперь вместо `NULL` пользователь увидит:

```text
Телефон не указан
```

Это особенно полезно при формировании отчётов.

college.students

# Пример с переменной

Теперь сделаем небольшой T-SQL-скрипт.

Пусть необходимо проверить возраст студента:

```sql
DECLARE @age INT;

SELECT @age = age
FROM college.students
WHERE id = 1;

IF @age >= 18
    PRINT N'Студент совершеннолетний';
ELSE
    PRINT N'Студент несовершеннолетний';
```

Здесь мы объединили:

```text
переменную
+
SELECT
+
условие
```

Последовательность работы:

```text
college.students
       ↓
SELECT
       ↓
@age
       ↓
IF
       ↓
результат
```

---

# Пример с переменной и CASE

Теперь используем `CASE`.

```sql
DECLARE @age INT;

SELECT @age = age
FROM college.students
WHERE id = 1;

SELECT
    CASE
        WHEN @age >= 18 THEN N'Совершеннолетний'
        ELSE N'Несовершеннолетний'
    END AS status;
```

В этом случае:

```text
SELECT
```

получает данные.

Переменная:

```text
@age
```

хранит полученное значение.

А:

```text
CASE
```

определяет итоговый результат.

---

# Зачем вообще нужны переменные и CASE?

На первый взгляд может показаться, что всё это можно сделать обычным `SELECT`.

И действительно, во многих случаях можно.

Но переменные и управляющие конструкции становятся особенно полезны, когда появляется программная логика.

Например:

```text
получить данные
      ↓
сохранить значение
      ↓
проверить условие
      ↓
выполнить действие
      ↓
получить результат
```

Именно здесь T-SQL начинает отличаться от обычного SQL-запроса.

---

# Небольшой практический пример

Создадим несколько переменных:

```sql
DECLARE @price DECIMAL(10,2) = 1500;
DECLARE @discount DECIMAL(5,2) = 10;
```

Рассчитаем стоимость со скидкой:

```sql
DECLARE @price DECIMAL(10,2) = 1500;
DECLARE @discount DECIMAL(5,2) = 10;

SELECT
    @price AS Price,
    @discount AS Discount,
    @price - (@price * @discount / 100) AS FinalPrice;
```

Результат:

```text
Price    Discount    FinalPrice
--------------------------------
1500     10          1350
```

Здесь используются:

```text
переменные
+
DECIMAL
+
арифметические выражения
```

---

# Практический пример с условием

Теперь определим размер скидки автоматически.

```sql
DECLARE @price DECIMAL(10,2) = 1500;
DECLARE @discount DECIMAL(5,2);

IF @price >= 1000
    SET @discount = 10;
ELSE
    SET @discount = 5;

SELECT
    @price AS Price,
    @discount AS Discount,
    @price - (@price * @discount / 100) AS FinalPrice;
```

Логика:

```text
Цена >= 1000?
       │
   ┌───┴───┐
  ДА      НЕТ
   │        │
  10%      5%
   │        │
   └───┬────┘
       ↓
  Итоговая цена
```

Это уже небольшой полноценный T-SQL-скрипт.

# IF или CASE?

Важно научиться выбирать подходящий инструмент.

Если необходимо выполнить разные инструкции:

```sql
IF
```

Например:

```sql
IF @age >= 18
    PRINT N'Доступ разрешён';
ELSE
    PRINT N'Доступ запрещён';
```

Если необходимо получить значение:

```sql
CASE
```

Например:

```sql
SELECT
    CASE
        WHEN age >= 18 THEN N'Доступ разрешён'
        ELSE N'Доступ запрещён'
    END AS access_status
FROM college.students;
```

Можно запомнить:

```text
IF → управление выполнением

CASE → вычисление значения
```

---

# Типичная ошибка при работе с типами

Рассмотрим:

```sql
DECLARE @age INT = 18;
DECLARE @name NVARCHAR(100) = N'Иван';
```

Нельзя бездумно смешивать типы:

```sql
SELECT @age + @name;
```

SQL Server попытается выполнить преобразование типов и может завершить запрос ошибкой.

Поэтому выражения должны быть логически и типово корректными.

Например:

```sql
SELECT @age + 1;
```

или:

```sql
SELECT @name + N' Петров';
```

работают корректно.

# Преобразование типов

Иногда необходимо специально преобразовать значение из одного типа в другой.

В SQL Server для этого используются, например:

```sql
CAST()
```

и:

```sql
CONVERT()
```

Например:

```sql
DECLARE @age INT = 18;

SELECT CAST(@age AS NVARCHAR(10));
```

Теперь число:

```text
18
```

будет преобразовано в строковое значение.

Пока достаточно запомнить сам принцип:

```text
один тип
   ↓
CAST / CONVERT
   ↓
другой тип
```

Подробно преобразование типов рассмотрим по мере необходимости в следующих темах.

---

# Большой пример

Объединим основные возможности занятия.

```sql
USE CollegeDB;
GO

DECLARE @studentId INT = 1;
DECLARE @studentName NVARCHAR(100);
DECLARE @age INT;
DECLARE @averageGrade DECIMAL(4,2);

SELECT
    @studentName = name,
    @age = age,
    @averageGrade = average_grade
FROM college.students
WHERE id = @studentId;

SELECT
    @studentName AS StudentName,
    @age AS Age,
    @averageGrade AS AverageGrade,
    CASE
        WHEN @averageGrade >= 4.5 THEN N'Отличник'
        WHEN @averageGrade >= 3.5 THEN N'Хорошист'
        WHEN @averageGrade >= 3.0 THEN N'Успевает'
        ELSE N'Есть задолженности'
    END AS Result,
    CASE
        WHEN @age >= 18 THEN N'Совершеннолетний'
        ELSE N'Несовершеннолетний'
    END AS AgeStatus;
```

В этом примере мы:

1. выбрали базу данных;
2. создали несколько переменных;
3. получили данные из таблицы;
4. сохранили их в переменные;
5. использовали арифметические и логические условия;
6. применили `CASE`;
7. получили итоговый результат.
